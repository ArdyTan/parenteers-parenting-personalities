# Contoh Post Editorial Parenteers

6 Oktober 2026 · Tiga contoh dalam dua metode produksi.

- Buka `index.html` untuk perbandingan dan toggle grid.
- `comparison.png`: contact sheet kedua versi.
- `vector/`: tiga SVG dan PNG tanpa image generation untuk ilustrasinya.
- `gpt-image/`: tiga SVG dan PNG dengan ilustrasi GPT Image serta layout lokal.
- `design-system/`: panduan, tokens JSON, board SVG/PNG, dan contoh overlay grid.
- `assets/`: logo resmi, font proyek, lisensi, serta ilustrasi generatif asli.
- `copy.json` dan `captions.md`: copy yang dapat dipakai ulang, caption dan alt text.
- `image-prompts.json`: prompt final dan metode built-in untuk ketiga ilustrasi.
- `qa-report.json`: bukti ukuran, batas aman, font, dan preview lokal.

PNG post: 1080 × 1350 px. Grid: 90 × 90 px. Margin aman: 90 px setiap sisi.
SVG memiliki grup terpisah untuk text, ilustrasi, dan brand. Import Figma belum
diperiksa; perlakuan font/text importer dijelaskan dalam design system. Ilustrasi
GPT tetap raster. Semua preview dan PNG dibuat lokal; tidak ada publikasi.
