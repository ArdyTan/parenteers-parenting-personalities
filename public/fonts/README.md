# Font bundle

Self-hosted Phase 0 subsets sourced from the pinned Fontsource packages in `devDependencies`:

- `fraunces-latin-variable.woff2` — Fraunces Latin variable subset with `wght` + `SOFT` axes.
- `plus-jakarta-sans-latin-variable.woff2` — Plus Jakarta Sans Latin `wght` variable subset.

Combined font payload: 89,780 bytes, below the 120 KB budget in `plan.md` §10. The full Fraunces all-axis file is intentionally not shipped because it would exceed the budget before compression. License texts are stored beside the font files.
